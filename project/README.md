Employee Data Analysis
Project Overview
This project focuses on analyzing employee data using Python and Pandas to understand employee attrition, salary distribution, and job satisfaction.

Dataset
IBM HR Analytics Employee Attrition & Performance dataset.

Tools Used
Python
Pandas
Jupyter Notebook
Git and GitHub
Initial Data Analysis
The following operations were performed:

df.shape – Checked the number of rows and columns.
df.info() – Checked column names and data types.
df.describe() – Generated statistical summaries.
df.isna().sum() – Checked missing values.
df.duplicated().sum() – Checked duplicate records.
Business Questions
Which department has the highest employee attrition?
Which age group has the highest attrition?
What is the average monthly income by department?
Does job satisfaction affect employee attrition?
How does years at the company relate to employee attrition?
